# ZorPDF

ZorPDF is a Next.js PDF toolkit with a public homepage, PDF conversion tools, public login, customer-care access and a super-admin panel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Environment

Configure your Supabase variables in `.env.local` using the names used by `lib/supabase.ts`.

No third-party builder branding or builder-specific project metadata is required.
